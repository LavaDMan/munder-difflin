# PR evidence images

Terminal captures attached to pull requests against
[chaitanyagiri/munder-difflin](https://github.com/chaitanyagiri/munder-difflin).

Kept on this orphan branch, not on the PR branches, so the proposed diffs stay
limited to the change itself.

Every image is verbatim real command output, rendered to PNG only because the
`PR evidence` check matches on an image or video and cannot match pasted text.
Nothing is composed or edited for the picture.
